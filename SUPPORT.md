# Support

Thank you for using `EricksonLopez.SqlBuilder`. If you need help, please use the channels below.

## Community Support

- **GitHub Issues:** For bug reports and feature requests. Please use the provided [issue templates](.github/ISSUE_TEMPLATE/).
- **GitHub Discussions:** For Q&A, general discussions, architecture questions, and sharing how you use the library.
