# Level 4: Advanced Integration

## Overview

Demonstrates complex joins, subqueries, CASE expressions, conditional logic, and date-part filtering.

## Key APIs Covered

- `.LeftJoin()`, `.RightJoin()`, `.FullOuterJoin()`, `.CrossJoin()`.
- `.SubqueryJoin()` and `.FromSelect()`.
- `SelectCase` for typed conditional branches.
- `WhereDay()`, `WhereMonth()`, `WhereYear()`.
